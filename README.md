
# Personal Notes Hub

A simple and user-friendly notes management application built using HTML, CSS, JavaScript, Node.js, Express.js, and SQLite.

## About the Project

Personal Notes Hub helps users create, organize, update, and delete their personal notes. It provides an easy way to manage important information in one place.

## Features

- Create new notes
- Edit and delete existing notes
- Search notes
- Organize notes by category
- Add tags to notes
- Mark notes as favorites
- Pin important notes
- Choose note colors
- Store notes using SQLite
- Backend API using Node.js and Express.js

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite
- **Version Control:** Git and GitHub

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/sneha500/personal-notes-hub.git
```

### 2. Open the project folder

```bash
cd personal-notes-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

### 5. Open the application

Visit the following URL in your browser:

http://localhost:3000
